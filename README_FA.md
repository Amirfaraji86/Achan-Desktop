# آچان (Achan) — Windows 7 SP1 / 10 / 11 x64

**Made by Faraj**

آچان یک رابط سبک برای راه‌اندازی هسته شبکه‌ای مبتنی بر پراکسی محلی، DNS امن و تونل TUN در ویندوز است. رابط فارسی و راست‌به‌چپ است و وضعیت موتور شبکه، پراکسی، DNS امن و تونل را جداگانه نمایش می‌دهد. گزارش‌های فنی فقط در پنجره «گزارش تشخیصی» و فایل محلی ذخیره می‌شوند.

## نصب و به‌روزرسانی

برای Windows 10/11 و Windows 7 SP1 x64، فایل Setup مخصوص همان سیستم‌عامل را از بخش **Releases** مخزن دریافت کن. نصب‌کننده همه فایل‌های Runtime را همراه خود دارد و نصب Python روی رایانه مقصد لازم نیست.

نسخه نصب‌شده آچان انتشارهای رسمی GitHub را به‌صورت دوره‌ای بررسی می‌کند. در صورت وجود نسخه جدید، نصب‌کننده مناسب سیستم‌عامل دانلود می‌شود، اندازه و SHA-256 آن بررسی می‌شود، اتصال شبکه به شکل کنترل‌شده خاموش می‌شود، برنامه بسته و نصب‌کننده اجرا می‌شود و پس از نصب آچان دوباره باز می‌شود. بررسی دستی نیز از دکمه «بررسی به‌روزرسانی» داخل برنامه در دسترس است.

**محدودیت مهم UAC:** چون نصب آچان در مسیر سیستمی ویندوز و با دسترسی مدیر انجام می‌شود، ممکن است Windows هنگام نصب نسخه جدید پنجره تأیید UAC نشان دهد. آچان این حفاظت امنیتی ویندوز را دور نمی‌زند. در صورت لغو UAC، نسخه فعلی دوباره اجرا می‌شود. نسخه Portable به‌صورت خودکار درجا به‌روزرسانی نمی‌شود و باید با بسته Portable جدید جایگزین شود.

**ارتقای نخست از نسخه 1.0.3:** نسخه‌های قبلی Updater داخلی نداشتند؛ بنابراین کاربران 1.0.3 باید یک بار نسخه 1.1.0 را دستی نصب کنند. بعد از این ارتقا، نسخه‌های بعدی می‌توانند از داخل برنامه دریافت شوند.

## پیش‌نیاز Windows 7

نسخه Windows 7 فقط برای Windows 7 SP1 شصت‌وچهاربیتی ساخته می‌شود. برای بارگذاری درایور امضاشده، به‌روزرسانی‌های SHA-2 مایکروسافت (KB4474419 و KB4490628) باید نصب شده باشند و سپس ویندوز Restart شود. نصب‌کننده Visual C++ 2015–2019 Runtime را نیز در صورت نیاز نصب می‌کند.

## ساخت و انتشار برای توسعه‌دهنده

دو Workflow مستقل در مسیر `.github/workflows` قرار دارند:

- `build-windows.yml`: ساخت Windows 10/11 با Python 3.13.
- `build-windows7.yml`: ساخت Windows 7 SP1 x64 با Python 3.8.10 و وابستگی‌های سازگار.

برای آماده‌سازی نسخه بعدی از اسکریپت `scripts/publish-release.ps1` استفاده کن؛ نمونه اجرا و گزینه Commit/Push در `RELEASE_GUIDE_FA.md` توضیح داده شده است. بعد از Push، دو Workflow به‌طور خودکار خروجی‌های هر پلتفرم را می‌سازند و Tag و Releaseهای مستقل را منتشر می‌کنند. ایجاد دستی Tag یا Release و بارگذاری دستی Assets لازم نیست.

هر Release شامل Setup، Portable، بسته Distribution و فایل JSON مخصوص Updater است. Manifest شامل شماره نسخه، نام Setup، اندازه و SHA-256 فایل نصب‌کننده است. فایل Setup قبل از اجرا در سیستم کاربر با Manifest تطبیق داده می‌شود.

برای ساخت محلی، Python مناسب پلتفرم، بسته‌های `requirements.txt` یا `requirements-win7.txt`، PyInstaller و Inno Setup 6 لازم‌اند. این نیازمندی‌ها فقط برای ساخت هستند؛ نه برای کاربر نهایی.

## کارکرد شبکه و محدودیت‌ها

- پراکسی HTTP فقط روی `127.0.0.1:4525` گوش می‌دهد.
- DNS از DoH روی `sky.rethinkdns.com` استفاده می‌کند.
- `tun2proxy` با حالت DNS مجازی، ترافیک IPv4/TCP را از رابط Wintun به پراکسی محلی هدایت می‌کند.
- اتصال خروجی پراکسی به رابط فیزیکی ذخیره‌شده پیش از تغییر Routeها مقید می‌شود تا حلقه مسیریابی ایجاد نشود.
- هنگام خاموش کردن، آچان ابتدا به tun2proxy سیگنال پایان کنترل‌شده می‌دهد تا Routeهای اصلی ویندوز بازیابی شوند.
- آچان VPN ناشناس‌کننده نیست، سرور راه‌دور ندارد و IP عمومی را مخفی نمی‌کند.
- پراکسی HTTP مورد استفاده UDP عمومی را منتقل نمی‌کند؛ بازی‌ها، تماس‌ها و QUIC/HTTP3 ممکن است کار نکنند.
- نتیجه به ISP، مسیر DoH و فیلترینگ شبکه بستگی دارد و باز شدن هیچ سایت خاصی تضمین نمی‌شود.
- اگر قطع اتصال اجباری شود یا پردازش تونل ناگهانی بسته شود، ممکن است بازیابی Routeها کامل نشود؛ در این حالت ویندوز را Restart کن.
- Windows 7 و Python 3.8 از چرخه پشتیبانی امنیتی خارج شده‌اند؛ استفاده از ویندوز پشتیبانی‌شده توصیه می‌شود.

## گزارش‌ها

گزارش فنی در مسیر `%LOCALAPPDATA%\Achan\logs\achan.log` و رخدادهای Updater در `updater.log` ذخیره می‌شوند. داده‌ای به سرور اختصاصی آچان ارسال نمی‌شود؛ برای بررسی نسخه فقط GitHub API و فایل‌های Release رسمی استفاده می‌شوند.
