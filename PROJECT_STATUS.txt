Achan 1.0.3 - Windows x64 source / cloud-build package
UI: compact dark green + black, Persian, single-instance, animated power toggle, four readiness stages, hidden rotating diagnostic log
Runtime: local HTTP CONNECT proxy, DoH, tun2proxy 0.8.7, Wintun 0.14.1
Windows 10/11 build: Python 3.13, current dependency set, standard tun2proxy x64 MSVC target, current VC++ runtime
Windows 7 build: separate workflow, Python 3.8.10, Python 3.8-pinned dependencies, tun2proxy x86_64-win7-windows-msvc target, Wintun 0.14.1 and VS 2019 14.29 runtime
Installer: Inno Setup 6; Windows 7 profile requires Windows 7 SP1 x64
Compatibility changes: DNS cleanup uses WMI available on Windows 7 instead of newer NetAdapter/NetTCPIP PowerShell cmdlets
Cloud builds: .github/workflows/build-windows.yml and .github/workflows/build-windows7.yml
Status: source and CI pipeline prepared. The Windows 7 package must still be built in Actions and tested on a real Windows 7 SP1 x64 machine/VM before claiming fully verified compatibility.
Important: Windows 7 and Python 3.8 are end-of-life. Achan is not an anonymizing VPN; no remote relay; public IP is not hidden; generic UDP is not proxied.
