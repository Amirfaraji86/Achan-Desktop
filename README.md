#  Achan | آچان

### مدیریت هوشمند اتصال شبکه در ویندوز

آچان یه ابزار سبک و مینیماله که کمک می‌کنه اتصال شبکه ویندوز رو از طریق DNS امن، پراکسی محلی و تونل شبکه مدیریت کنی.

همه‌چیز از طریق یه رابط گرافیکی ساده انجام می‌شه؛ وضعیت اجزای مختلف رو می‌بینی و با یه کلید می‌تونی اتصال رو فعال یا غیرفعال کنی.

**ساخته‌شده با ❤️ توسط Faraj**

## ✨ امکانات

- 🖥️ رابط گرافیکی ساده، مدرن و فارسی
- 🔄 فعال و غیرفعال کردن اتصال با یک کلیک
- 🌐 استفاده از DNS over HTTPS (DoH)
- 🔌 ایجاد پراکسی HTTP محلی
- 🚀 مسیریابی ترافیک TCP از طریق تونل TUN
- 📡 استفاده از Wintun برای ایجاد رابط شبکه مجازی
- ✅ بررسی جداگانه وضعیت موتور شبکه، DNS، پراکسی و تونل
- 📝 گزارش تشخیصی برای پیدا کردن مشکلات اتصال
- 📦 نصب آسان؛ بدون نیاز به نصب Python روی سیستم مقصد

⚠️ نسخه ویندوز ۷ به‌روزرسانی‌های موردنیاز SHA-2 مایکروسافت را لازم دارد.

## ⚙️ آچان چطور کار می‌کنه؟

آچان از چند بخش تشکیل شده که کنار هم کار می‌کنن:

1. **DNS امن:** درخواست‌های DNS از طریق DoH به سرویس RethinkDNS ارسال می‌شن.
2. **پراکسی محلی:** یک پراکسی HTTP روی آدرس `127.0.0.1:4525` اجرا می‌شه.
3. **تونل شبکه:** ابزار `tun2proxy` و درایور Wintun برای هدایت ترافیک استفاده می‌شن.
4. **مدیریت اتصال:** آچان وضعیت مراحل رو بررسی می‌کنه و هنگام قطع اتصال، برای بازیابی تنظیمات شبکه تلاش می‌کنه.

## ⚠️ معایب و محدودیت‌ها

شفاف باشیم؛ آچان قرار نیست معجزه کنه!

- 🔴 **VPN نیست:** آچان سرور VPN راه‌دور ندارد و IP عمومی تو را مخفی نمی‌کند.
- 🔴 **پشتیبانی‌نکردن از UDP عمومی:** بازی‌های آنلاین، تماس‌های اینترنتی و بعضی برنامه‌هایی که به UDP وابسته‌اند ممکن است درست کار نکنند.
- 🔴 **QUIC و HTTP/3:** ممکن است در بعضی برنامه‌ها با مشکل مواجه شوند.
- 🔴 **وابستگی به شرایط شبکه:** عملکرد برنامه به ISP، مسیر ارتباطی و دسترسی به سرویس DNS بستگی دارد.
- 🔴 **نیاز به دسترسی مدیر:** برای فعال‌کردن تونل شبکه باید دسترسی Administrator داشته باشی.
- 🔴 **محدودیت ویندوز ۷:** این سیستم‌عامل دیگر به‌روزرسانی امنیتی عمومی دریافت نمی‌کند و استفاده از ویندوزهای پشتیبانی‌شده جدیدتر توصیه می‌شود.

بازشدن سایت‌های خاص یا عبور از تمام محدودیت‌های اینترنت تضمین‌شده نیست.

## 🔐 حریم خصوصی و گزارش‌ها

گزارش‌های فنی برنامه به‌صورت محلی ذخیره می‌شوند و در حالت عادی به سرور اختصاصی آچان ارسال نمی‌شوند.

مسیر ذخیره گزارش:

```text
%LOCALAPPDATA%\Achan\logs\achan.log
```

توجه داشته باش که درخواست‌های DNS برای پردازش به سرویس DoH انتخاب‌شده ارسال می‌شوند.
