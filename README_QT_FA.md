# Achan Modern UI — نسخه اصلاح‌شده

این بسته، رابط مدرن Achan را با PySide6 + Qt Quick بازنویسی می‌کند و هسته شبکه‌ای موجود را از `core/controller.py` حفظ می‌کند.

## امکانات این نسخه

- پنجره بدون نوار عنوان پیش‌فرض، با دکمه‌های اختصاصی Minimize، Maximize/Restore و Close که آیکون‌ها با Canvas رسم می‌شوند.
- دکمه مرکزی Power با آیکون برداری واقعی و حلقه‌های متحرک؛ در حالت disconnected به‌درستی خاکستری/سبزِ کم‌رنگ باقی می‌ماند و در وضعیت اتصال واقعی سبز می‌شود.
- پشتیبانی فارسی و انگلیسی؛ انتخاب زبان در تنظیمات ذخیره می‌شود.
- صفحات Dashboard، Network Monitor، Services، Settings، Updates و About.
- وضعیت چهار مرحله اتصال از callback واقعی `NetworkController` خوانده می‌شود؛ حالت Demo صرفاً شبیه‌سازی است.
- مانیتور ترافیک با شمارنده‌های سیستم از طریق `psutil` و Ping واقعی ICMP با `ping.exe`؛ در صورت نبود داده، مقدار ساختگی نمایش داده نمی‌شود.
- بررسی انتشار رسمی از طریق `core/update_client.py` موجود پروژه، دانلود نصب‌کننده و اعتبارسنجی اندازه/SHA-256 توسط همان UpdateClient.
- بررسی خودکار روزانه برای نسخه نصب‌شده (قابل خاموش/روشن‌کردن از Settings).
- گزارش فنی و کپی گزارش.

## نصب/جایگزینی

این ZIP را در ریشه مخزن Achan استخراج و فایل‌های هم‌نام را جایگزین کن. ساختار باید این‌گونه باشد:

```text
Achan/
  main_qt.py
  requirements-qt.txt
  qt_ui/main.qml
  core/controller.py          # از پروژه فعلی حفظ شود
  core/update_client.py       # از پروژه فعلی حفظ شود
```

در CMD داخل پوشه اصلی پروژه:

```cmd
python -m pip install -r requirements-qt.txt
```

برای پیش‌نمایش بی‌خطر (هیچ تنظیم شبکه‌ای تغییر نمی‌کند):

```cmd
run-modern-demo.bat
```

برای اجرای واقعی:

```cmd
run-modern.bat
```

اجرای واقعی فقط روی Windows 10/11 x64 است. Windows 7 باید همچنان از نسخه قدیمی Tkinter استفاده کند.

## نکات عملکردی و شفافیت

- Demo برای آزمایش بصری است و وضعیت اتصال را شبیه‌سازی می‌کند.
- نسخه واقعی از `NetworkController` فعلی استفاده می‌کند. وضعیت سرویس‌ها تنها با رویدادهای کنترلر تغییر می‌کند.
- ترافیک از شمارنده تجمیعی رابط‌های ویندوز می‌آید؛ ممکن است آداپتور مجازی هم در آمار لحاظ شود.
- Ping با `ping.exe` به 1.1.1.1 انجام می‌شود؛ در صورت مسدودبودن ICMP مقدار `—` می‌ماند.
- updater از Manifest موجود پروژه استفاده می‌کند و قبل از ارائه فایل نصب، اندازه و SHA-256 را بررسی می‌کند. نصب خودکار فقط وقتی فعال است که فایل‌های `AchanUpdater.exe` و `Achan.exe` در نصب موجود باشند؛ در حالت توسعه، نصب‌کننده تأییدشده باز می‌شود تا کاربر نصب را دستی کامل کند.
- `main.py` و `core/` قدیمی حذف یا بازنویسی نمی‌شوند. برای انتشار، Workflow ساخت Qt باید به تنظیمات نسخه جدید اشاره کند.

## ساخت EXE آزمایشی

```cmd
python -m PyInstaller --noconfirm --clean --onedir --windowed --name AchanModern --add-data "qt_ui;qt_ui" --collect-all PySide6 --collect-all shiboken6 --collect-all psutil main_qt.py
```

پس از ساخت، فایل‌های `bin/tun2proxy-bin.exe` و `bin/wintun.dll` و در صورت استفاده از نصب خودکار، `AchanUpdater.exe` باید در بسته نهایی کنار برنامه/مسیر مورد انتظار قرار داشته باشند.
